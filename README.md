## CoolE KeyFactor｜廠務檢驗台
這幾天把「哪些製程參數在影響品質」做成產線檢驗台，不是分析師筆記本。

- 白話排出關鍵因子與影響力，What-if 先模擬再改機台
- 迴歸與 OK／NG 分類；模型經品保核准才成為現場依據
- 商業版補上製程視窗、偏移告警、產線授權、稽核包與 MES 回寫
- ASP.NET 8、Vue 3、Python（scikit-learn／XGBoost）

開源版：[CoolE-AI-KeyFactor](https://github.com/pigqig/CoolE-AI-KeyFactor)
