## 工廠現場：這是本業

MES 不是再做一套報表。現場要的是：**現在這張工單在哪、缺什麼料、何時能出、帳與庫對不對得上。**

- **從排程到出貨** — APS 排得出來、MES 收得回去、倉庫出得了、ERP 帳對得上  
- **跨系統整合** — **ERP、APS、MES、WMS** 不是各過各的；工單、庫存、在製、出貨要同一件事實  
- **地端、私有雲** — 廠內資料留在廠內；OT／IT／Data 收到能上線，不是停在簡報  

帶團隊走完需求、POC、導入、維運。系統商與廠務聽得懂的話，我用現場的話講。

## 幫企業導入 AI（用得起來才算）

AI 只做工廠與辦公室**當天會按下去的事**：

| 用在哪 | 現場得到什麼 |
| --- | --- |
| **檢查** | 影像與品質：人臉／車牌／製程外觀，異常當下看得到 |
| **分析** | 關鍵因子、What-if：先知道該調哪一項，再動機台 |
| **助手** | 看著操作寫 SOP、整理檔案、回答「這張單下一步」 |
| **翻譯** | 會議、字幕、跨語系文件，長影片也能拆段做完 |
| **知識庫** | 把現場做法、規範、經驗變成找得到、問得到的內容 |

模型要能解釋、能模擬；進產線當標準，要過品保核准——不是把黑盒子丟給值班。
